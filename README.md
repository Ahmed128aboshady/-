## مميزات الداشبورد والتطبيق التفاعلي:

1. **تصميم أكاديمي مخصص للهاتف المحمول:** شريط تنقل سفلي سريع بيد واحدة، ووضع ليلي/نهاري، وحفظ تلقائي للتقدم.
2. **القارئ الصوتي الذكي:** إمكانية الاستماع للشرح والملخصات صوتياً عبر السماعات أثناء التنقل مع التحكم في سرعة الصوت.
3. **الموسوعة التعليمية (9 موديولات كاملة):** تغطية شاملة لكافة المفاهيم، التصنيفات، الجداول، والمعادلات بدون أي اختصار مخل.
4. **كروت الذاكرة السريعة (45 Flashcards):** بطاقات تفاعلية للتقليب والحفظ النشط بنظام التكرار المتباعد.
5. **محاكي الاختبار المهني (50 سؤال اختيار من متعدد):** تصحيح فوري مع شرح وتعليل تربوي دقيق لكل بديل، وتتبع نسبة الدقة والدرجة.
6. **مفخخات وتريكات الامتحان:** جداول مقارنة حاسمة بين المفاهيم المتشابهة (القياس vs التقييم vs التقويم، التعزيز السلبي vs العقاب، إدارة الصف vs ضبط الصف، معاملات الصعوبة والتمييز).
7. **الباحث الفوري الذكي:** بحث لحظي بالكلمات المفتاحية وأسماء العلماء والمصطلحات.

## الأركان التسعة لمنهج التأهيل التربوي:

1. **تخطيط التدريس والمنهج المدرسي:** مستويات التخطيط (بعيد، متوسط، وقصير)، عناصر الخطة، معادلة ماجر للأهداف السلوكية، هرم بلوم وتعديل أندرسون، كراثوول، سيمبسون، والمنهج القديم vs الحديث.
2. **مهارات التدريس الصفي وتنفيذ الدرس:** التهيئة الحافزة (توجيهية، انتقالية، تقويمية)، الأسئلة الصفية وزمن الانتظار (ماري باد رو)، التعزيز الصفي (إيجابي وسلبي)، تنويع المثيرات، وغلق الدرس (إدراكي ونمائي).
3. **استراتيجيات التعليم والتعلم والتعلم النشط:** العصف الذهني وقواعده الأربعة، حل المشكلات لجون ديوي، التعلم التعاوني وأدواره وركائزه، دورة التعلم الخماسية 5Es، تقنيات التعلم النشط السريعة (ورقة الدقيقة الواحدة، النقطة الأكثر غموضاً، K-W-L)، والأنماط التعليمية التسعة.
4. **إدارة الصف وضبط الصف المدرسي:** الفرق الجوهري بين إدارة الصف (استباقية ووقائية) وضبط الصف (علاجي ورد فعلي)، أنماط الإدارة (تسلطي، فوضوي، ديمقراطي)، مبادئ جاكوب كونين الأربعة (Withitness, Overlapping, Smoothness, Group Alerting)، وقواعد السلوك الصفي.
5. **المشكلات السلوكية وتعديل السلوك الصفي:** السلوك الاستجابي والإجرائي، فنيات تعديل السلوك (التعزيز المتقطع المتغير، التشكيل، التسلسل، النمذجة، الإطفاء والانفجار الانطفائي، تكلفة الاستجابة، الإقصاء Time-out، التصحيح الزائد، ومبدأ بريماك).
6. **التواصل التربوي الفعال ولغة الجسد:** عناصر منظومة الاتصال والتشويش، قاعدة ألبرت مهرابيان (55% جسد، 38% صوت، 7% كلمات)، لغة الأكف والعيون، المسافات المكانية لإدوارد هول، وبوصلة الإقناع الأرسطية (Ethos, Logos, Pathos, Kairos).
7. **القياس والتقويم وبناء الاختبارات:** الفرق بين القياس والتقييم والتقويم، أنواع التقويم (قبلي، بنائي، ختامي، تتبعي)، الصدق والثبات والموضوعية، جدول المواصفات ومعادلاته، معاملات الصعوبة والتمييز وفاعلية المشتتات، وأدوات التقييم الأصيل (ملف الإنجاز والروبرك).
8. **تكنولوجيا التعليم والمعلم الرقمي:** مفهوم تكنولوجيا التعليم كمنظومة، نموذج TPACK، نموذج سامر (SAMR) للدمج الرقمي، الصف المقلوب، التعليم المدمج، والمواطنة والأمان الرقمي.
9. **المهارات اللغوية للمعلم وأدواره المهنية والأخلاقية:** مهارات اللغة الاستقبالية والإنتاجية، فصاحة المعلم والتنغيم الصوتي، الأدوار الحديثة السبعة للمعلم (الميسر، الباحث الإجرائي، المرشد، القائد)، وميثاق الشرف الأخلاقي.
